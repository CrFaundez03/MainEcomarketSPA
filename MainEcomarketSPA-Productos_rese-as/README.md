# BEPYR - API REST para Ecomarket

Este proyecto Spring Boot implementa una API REST para gestionar productos y reseñas con una arquitectura basada en capas (Model, Repository, Service, Controller).

## Tecnologías
- Spring Boot
- Spring Web
- Spring Data JPA
- Lombok
- MySQL

## Uso
1. Configura tu base de datos MySQL local con nombre `ecomarket`.
2. Ejecuta el proyecto desde tu IDE o con `./mvnw spring-boot:run`.
3. Usa Postman para poblar la base de datos. Ver ejemplos en la documentación.
